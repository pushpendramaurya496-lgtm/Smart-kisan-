# Chakki Smart AI - Backend & Cloud Architecture (AWS Ready)

This directory is reserved for the scalable Node.js backend.

## Planned Architecture:
1. **Runtime:** Node.js (Express / Fastify)
2. **Cloud Hosting:** AWS (EC2 / AWS App Runner / ECS with Docker)
3. **Database:** MongoDB Atlas / AWS DocumentDB or PostgreSQL (Prisma ORM)
4. **Storage:** AWS S3 (for PDF Invoices & WhatsApp Audio clips)
5. **WhatsApp Integration:** WhatsApp Business Cloud API (Meta)
6. **Authentication:** JWT with Phone OTP (Firebase Auth / AWS Cognito)
7. **CI/CD:** Automated GitHub Actions deploying to AWS on push to `main`.
